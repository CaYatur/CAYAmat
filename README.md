# CAYAmat (2018)

2018 · İlk masaüstü uygulamam: süreli çarpma pratiği oyunu (C# WinForms). Kaynak, derlenmiş sürümden geri kazanıldı.

İlkokuldayken yazdığım **ilk masaüstü uygulamam**. Süreli bir çarpma pratiği oyunu:

- "Soru getir" ile rastgele bir çarpma sorusu (1–19 × 1–9) gelir
- Doğru cevap +10, yanlış cevap −10 puan
- Başlat düğmesiyle süre işler; süre bitince oyun durur, "Tekrar" ile sıfırlanır
- Açılışta "Yükleniyor…" ekranı

*My first desktop app (2018, primary school): a timed multiplication practice game in C# WinForms.*
